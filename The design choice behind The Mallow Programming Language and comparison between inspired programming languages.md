
# Introduction
 In this article we will explain the design choice laying behind the *Mallow Programming Language*, the decision progress and we will compare these choices to inspired programming languages to design the Mallow Programming Language such as *PHP*, *JavaScript*, *Rust* and *C*. We are going to explain each features of these inspired languages, criticise/commend each aspect of it and clarify the Mallow solution/decision of these. 
 
 We expect that our dear readers already have some level of general programming and algorithm understanding.
